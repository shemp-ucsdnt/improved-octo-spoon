# Chervil Construct Roster (canonical)

Source table supplied directly by the project owner on 2026-08-07/08, reviewed via a
PDF export, and approved to fully replace the `player-mechanics.pdf` Section 3
construct roster. This is now the single source of truth for Chervil's 11
constructs — implemented in `Unity/Assets/Scripts/TestMap/TestMapBuilder.cs`
(`ConfigureConstructs`) and `Unity/Assets/Scripts/Chervil/ConstructDefinition.cs`.
Sorrel's forms and Thyme's spells are unaffected and still come from
`player-mechanics.pdf`.

See `HANDOFF.md` for the design-liberty notes on what got mechanically wired
(deploy MP cost, Mobile/Immobile upkeep split) versus what's description-only
because no supporting system exists yet (stealth, phase-dash, invisibility,
magnetism, partial single-thread refunds, HP↔MP conversion).
